FEATURE: Admin Dashboard Integration
- Document complete dashboard integration with all components
- Threat reporting form with reactive validations
- Real-time alerts with WebSocket integration
- adminGuard protection on /dashboard route
- Full responsive design (mobile, tablet, desktop)

ARCHITECTURE:
- Hexagonal architecture (domain/application/infrastructure/presentation)
- Facade Pattern: AuthService, ThreatService, WebSocketService
- Repository Pattern: AuthRepository, ThreatRepository, WebSocketRepository
- Use Case Pattern: LoginUseCase, ReportThreatUseCase
- Observer Pattern: RxJS BehaviorSubject for reactive state
- Dependency Inversion: Abstract classes for high cohesion, low coupling

SOLID PRINCIPLES:
- Single Responsibility: Each component has one responsibility
- Open/Closed: Extensible through interfaces and abstractions
- Liskov Substitution: Interchangeable repository implementations
- Interface Segregation: Domain-specific interfaces
- Dependency Inversion: Dependencies on abstractions, not implementations

COMPONENTS INTEGRATED:
1. Dashboard View
   - Header with user info (username, role)
   - Logout button
   - Responsive grid layout
   - Adaptive design for all screen sizes

2. Threat Reporting Form
   - Type selection (malware, intrusion, phishing, ddos, ransomware)
   - Severity selection (low, medium, high, critical)
   - Source IP validation (required, IPv4 format)
   - Target IP validation (optional, IPv4 format)
   - Description validation (10-500 characters)
   - Loading states and success/error messages
   - Auto-reset after successful report

3. Real-time Alerts Visualization
   - AlertsComponent integrated
   - Automatic WebSocket connection
   - Real-time threat updates
   - Filters by type and severity
   - Search by description, IP, or ID
   - Pagination (10 alerts per page)
   - Statistics by severity
   - JSON export functionality
   - Connection status indicator

4. Route Protection
   - /dashboard protected with canActivate
   - JWT token verification in localStorage
   - Auto-redirect to /autenticacion if not authenticated
   - Lazy loading for optimization

USER FLOW:
1. Login → AuthService validates → Saves JWT token
2. Redirect → Router navigates to /dashboard → adminGuard validates
3. WebSocket Connect → AuthService auto-connects
4. Dashboard Loaded → User sees form + real-time alerts
5. Report Threat → ThreatService sends with JWT → Backend processes
6. WebSocket Notification → AlertsComponent receives and displays
7. Logout → AuthService disconnects WebSocket → Clears localStorage
